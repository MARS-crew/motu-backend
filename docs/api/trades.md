# 체결

[← API 명세서 목차](README.md)

내 주문의 체결 내역은 [주문 상세](orders.md#주문-상세)의 `trades`로 봅니다.

## 최근 체결

| 항목 | 내용 |
|------|------|
| API | `GET /api/trades/recent?stockId=` |
| 로그인 | 불필요 |
| 응답 | `stockId`, `items[] { tradeId, price, qty, side, createDate }` — 최신순, 최대 5건 |

| `side` | 뜻 | 표시 |
|------|------|------|
| `BUY` | 매수 체결 (매수 주문이 호가창의 매도 주문을 사들임) | 빨강 |
| `SELL` | 매도 체결 (매도 주문이 호가창의 매수 주문에 팔아넘김) | 파랑 |

| 에러 | 상황 |
|------|------|
| 404 `STOCK_NOT_FOUND` | 없거나 삭제된 상품 |

- 체결이 없으면 빈 배열입니다.
- 실시간 갱신은 [실시간 시세](charts.md#실시간-시세-sse)의 `trade` 이벤트로 받아 목록 맨 위에 넣고, 5건을 넘으면 마지막을 지우면 됩니다.
